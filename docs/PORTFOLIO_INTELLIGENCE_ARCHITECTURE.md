# Portfolio Intelligence Architecture

Terminal 2.5.4 combines approved products, investment scores, historical
features, market intelligence, and optional personal holdings.

The engine produces:

- actual enriched positions
- allocation by sealed-product group
- concentration and downside risk exposure
- position and candidate recommendations
- a bounded model allocation
- downside, current, upside, and five-year scenarios
- an executive portfolio summary

`data/terminal2/portfolio_holdings.csv` is intentionally ignored by Git.
Canonical dashboard outputs are written through the Dashboard Publisher.
