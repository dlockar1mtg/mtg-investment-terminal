## Why this stage exists

SL-6A found only two distinct underlying modeled return profiles across the
current 787 forecastable Secret Lairs.

Finite Monte Carlo sample variation therefore cannot be used to manufacture
product-level ordering.

## Primary ranking signal

CERTIFIED_CENTRAL_1Y_MODELED_RETURN

Higher modeled return ranks above lower modeled return.

This is the certified production forecast signal, not a newly fitted score.

## Evidence hierarchy inside identical return profiles

Evidence is used only when two or more products share the same underlying
modeled return profile.

The hierarchy is lexicographic:

1. own-history evidence class;
2. exact structural comparable support;
3. history span;
4. historical observation count;
5. exact structural comparable event count;
6. global comparable event count.

No values are multiplied by weights and no additive score is created.

## Genuine ties

After the full economic and evidence tuple is applied, products that remain
identical are co-ranked.

Secret Lair ID, product name, alphabetical order, current price, and Monte
Carlo random seed may not break a genuine investment tie.
