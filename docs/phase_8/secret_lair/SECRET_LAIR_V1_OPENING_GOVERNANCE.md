# Secret Lair V1 Opening Governance

## Starting point

Secret Lair V1 begins only after Collector and Pre-Collector are treated as completed governed lanes.

Secret Lair is not a copy of either prior product class.

## Existing repository infrastructure

The repository already contains Secret Lair:

- registry tooling;
- registry validation;
- source integration;
- price import tooling;
- historical/backfill tooling;
- discovery tooling;
- archive/recovery evidence;
- prior semantic and historical-performance work.

Every existing component must be classified before reuse.

Permitted preliminary classifications:

- REVIEW_FOR_REUSE
- REVIEW_FOR_ADAPTATION
- HIGH_PRIORITY_IDENTITY_AUDIT
- HIGH_PRIORITY_EVIDENCE_AUDIT
- PRESERVE_LEGACY_EVIDENCE
- RETIRE_FROM_PRODUCTION_AUTHORITY
- REBUILD

No existing Secret Lair component becomes V1 production authority merely because it already exists or previously passed tests.

## Required V1 governance sequence

1. Existing system inventory.
2. Canonical asset and identity audit.
3. Source hierarchy and evidence audit.
4. Canonical universe certification.
5. Current-price authority.
6. Historical-price authority.
7. Supply/liquidity authority.
8. Structural feature authority.
9. Empirical eligibility diagnostics.
10. Temporal OOS model tournament.
11. Product holdout / robustness / influence.
12. Final model selection.
13. 1-year forecast.
14. 3-year / 5-year forecast or governed scenario transfer.
15. Monte Carlo and uncertainty certification.
16. Investment ranking.
17. Purchase-analysis certification.
18. Secret Lair archive.
19. Unified MTG production export.
20. UIP acceptance and refresh orchestration.
