# Terminal 2.8.0 Phase 1 — Core Investment Intelligence

Phase 1 converts the existing forecast, historical, and market evidence into
consistent risk, confidence, recommendation, factor, explanation, model
coverage, and executive buy-list datasets.

## Publish

```bat
python terminal2_publish_core_intelligence.py
```

## Validate

```bat
python terminal2_core_intelligence_validate.py
```

Recommendations:

- Strong Buy
- Buy
- Watch
- Hold
- Avoid
- Insufficient Data

Confidence measures evidence strength. Risk measures downside and uncertainty.
Neither score is intended to replace the underlying forecast model.
